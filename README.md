### 💼 Experiencia Profesional

**Full-Stack Developer & Analista de Datos | Gobernación de Boyacá – Sec. Desarrollo Empresarial**
*Tunja, Colombia · 2025 – Actualidad*

- Desarrollo y mantenimiento del sitio web institucional **Colegio de Boyacá** (colboy.edu.co) con **Astro + WordPress headless** sobre servidor Rocky Linux/Apache, garantizando cumplimiento de estándares digitales gubernamentales (Resolución 1519/2020, Ley 1712).
- Construcción de bases de datos empresariales consolidadas de múltiples provincias de Boyacá, cruzando fuentes como SECOP II, Territorio de Sabores, Soy Boyacá y registros notariales.
- Desarrollo del **Censo de Emprendimientos Boyacá 2026**: dashboard interactivo con React, TypeScript, Vite, Recharts y SheetJS, complementado con tablero en Power BI.
- Automatización de reportes recurrentes en Python (pandas, openpyxl, ReportLab) para análisis de commodities (café, carbón, esmeraldas, cacao), cumplimiento PQRSDF y convocatorias departamentales.
- Creación de tema WordPress personalizado **"Boyacá Territorio de Sabores"** con PHP, Tailwind CSS v4 y Vanilla JS.
- Prospección comercial de compradores para productos agropecuarios boyacenses (peras de Paipa) mediante herramientas automatizadas y bases de datos estructuradas.

### 🌐 Proyecto Destacado: ProcuraBot – GovTech SaaS

> Plataforma de monitoreo inteligente de **SECOP II** orientada a MiPymes colombianas, con alertas automáticas vía WhatsApp y análisis de oportunidades de contratación pública.

**Stack:** Next.js 15 · Supabase · Vercel · Gemini 2.5 Flash · 360dialog (WhatsApp API) · Wompi (pagos)

**Funcionalidades clave:**
- 🔔 Alertas personalizadas de contratos por sector, entidad y monto
- 🤖 Análisis de pliegos con IA (Gemini) para evaluación rápida de requisitos
- 💳 Modelo freemium con tiers de suscripción y pagos en COP vía Wompi
- 📊 Dashboard de oportunidades con filtros avanzados por municipio, UNSPSC y régimen
